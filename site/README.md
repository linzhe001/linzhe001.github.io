# Linzhe Jiang academic homepage

This is the published static homepage under `site/`. Research projects and notes are built independently in the sibling `projects` and `blog` repositories and published at `/projects/` and `/blog/`.

The old al-folio site and its Git history remain in this repository; a complete local archive was taken before migration. The GitHub Pages workflow publishes only this `site/` directory. To edit the homepage, update `site/index.html`, `site/stylesheet.css`, and, for publication filtering, `site/site.js`. Keep research claims and publication data aligned with `_bibliography/papers.bib` and check links to the other two sites.

Layout inspired by [Teo Ren](https://github.com/TeoREN0217/teoren0217.github.io) and [Jon Barron](https://github.com/jonbarron/jonbarron.github.io). Do not copy anyone's personal photos or text.
